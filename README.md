# 抖音评论红字（Douyin Red Comment）

给抖音**网页版**评论注入 `text_extra` 富文本标记，让评论在**别人的客户端**里显示红色 / 位置 / 话题蓝等样式。

纯油猴脚本 · 不需要安卓设备 · 不依赖任何外部服务 · 无远程配置

> 关键词：抖音 · 评论 · 红字 · 彩色字体 · 变色 · 油猴脚本 · Tampermonkey · text_extra
>
> 当前版本：**v4.0.0**（2026-11 实测）
> 已知稳定可用的样式：**红字**（type 21）

---

## 它是怎么工作的（一句话版）

抖音的评论从来不是纯文本。每条评论都带一个 `text_extra` 数组，描述「正文第 N 到 M 个字符是什么样式」。**颜色是数据，不是本地 CSS**：

1. 你在网页发评论 → 脚本在请求发出前把 `text_extra` 塞进 body
2. 服务端原样存进数据库
3. 任何人（手机 / 网页 / iOS / 安卓）拉这条评论，都用自己的官方客户端按 `type` 渲染颜色

所以**别人不需要装任何东西**就能看到样式。

详细逆向过程与实测数据见 [`docs/PRINCIPLE.md`](docs/PRINCIPLE.md)、枚举表见 [`docs/TYPES.md`](docs/TYPES.md)。

## 功能

| 样式 | 说明 | 实测状态 |
|---|---|---|
| **红字** | `type: 21`，搜索命中样式，新版评论区渲染为红/深色黄 | ✅ 稳定，人人可见 |
| **位置** | `type: 33` + 正文加 `[位置]` 前缀 + 可选 `poi_id` | ⚠️ 服务端接受，web 端可能不渲染 |
| **话题蓝** | `type: 1` + `hashtag_name`，正文自动加 `#话题名#` | ⚠️ 带前后缀才可能可见 |
| **红蓝·连续** | DouX 原版：每字一段，`21`/`1` 交替 | ⚠️ `type 1` 在 web 端可能被剥离 |
| **红黄·隔字** | 线上样本手法：全 `21`，隔字染色 | ⚠️ 取决于客户端是否交替上色 |
| **自定义 type** | 手动指定任意 `type` 值 | 供实验 |

**结论：红字是唯一经过完整闭环验证、跨端可见的样式。**

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 `douyin-red-comment.user.js`，Tampermonkey 会自动弹出安装页；或手动复制全部内容到新脚本
3. 打开 `douyin.com` 任意视频评论区

> **Chrome / Edge 138+ 注意**：新版强制 `userScripts` API，需要在扩展详情里打开「**允许用户脚本**」，否则所有油猴脚本都不会执行。

---

## 使用

1. 评论区展开后，输入框右上方出现 **⚡ 样式** 按钮（找不到时用右上角胶囊兜底）
2. 点开面板 → 点一个样式（立即生效，不需要二次确认）
3. 正常发评论即可

面板里会显示：

- 胶囊状态：`红字 21 ▸ 待发` / `▸ 常开`
- 待发条：`✓ 红字 21 已就绪 · 全文`
- 发送结果：`上次发送：成功（已带样式）`

**持续模式**：开启后每条评论都自动带样式，不用每次点。

## 实测结论（2026-11，线上数据）

拉取真实视频评论 299 条，`text_extra.type` 分布：

```
{21: 39, 0: 5}   ← 39 条红字、5 条 @，0 条蓝字
```

真实红字评论的结构（服务端下发原文）：

```json
{
  "text": "是这个样子的么[捂脸]",
  "text_extra": [
    {"start": 0, "end": 18, "user_id": "", "type": 21, "hashtag_name": "", "hashtag_id": ""}
  ]
}
```

与脚本注入的结构**逐字段一致**。

### 几个常见误解

- **「评论区很多人发红蓝字」**：大多是 `type: 21` 的红字；所谓的「蓝」多数是 `@` 链接（`type: 0`，带真实 `user_id`/`sec_uid`）或 `#话题#`（`type: 1`，带 `hashtag_name`）
- **「蓝字为什么不生效」**：`type 1` 本质是话题样式，裸发（`hashtag_name` 为空）会被服务端剥离。能人人可见的蓝色只有话题蓝（带 `#话题#` 前后缀）
- **「红字是不是只在我这里显示」**：不是。红字写进了评论数据，任何人拉取都带这个标记

## 已知限制

1. **服务端校验**是唯一的不确定项。若抖音在落库侧校验「红字只允许特定身份」，样式会被剥离（表现为评论正常发出但无色）
2. **位置样式**在网页端没有入口，`poi_id` 需要自备；即使注入也不保证渲染
3. **蓝字（裸 type 1）** 在网页端基本不可见；DouX 的「无前后缀蓝字」是 App 旧版评论区专属渲染路径
4. **SPA 重渲染**：抖音切换视频会重建 DOM，脚本常驻监听并在 2 秒内自动恢复面板，但极短窗口内可能看不到入口
5. **风控**：篡改发布请求比纯 CSS 脚本敏感，建议小号测试，不要高频
